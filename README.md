# Mastery-Conditioned Edge–Cloud Model Selection — Simulation

Code simulation testing the core argument of `mastery-conditioned-edge-cloud-proposal.pdf`.
Full details: [`simulation/README.md`](simulation/README.md).

## How to run

```powershell
cd simulation
.\venv\Scripts\python.exe run_experiment.py
```

This one command downloads everything it needs and runs the full simulation.
Results (CSVs, JSON reports, PNG charts) go to `simulation/results/`.
